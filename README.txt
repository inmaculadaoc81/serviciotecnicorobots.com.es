ESTRUCTURA DE CONTENIDO
La plantilla original tenía 3 pilares (Ordenadores / Datos / Software).
Se han reconvertido a 3 pilares propios de un servicio técnico de
robots aspiradores:
- #averias — averías más frecuentes (no enciende, pierde succión, no
  navega, batería, WiFi/app, estación de autovaciado/fregado, ruidos).
- #piezas — piezas y recambios originales Dreame (batería, filtros,
  cepillos, módulo de fregado, sensores, ruedas).
- #recogida — recogida a domicilio (sustituye a "recuperación de
  datos" del original, adaptando la misma estructura de tarjetas).
